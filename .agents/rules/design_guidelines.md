# Design Guidelines: Wanderlust

1. **Strictly Mobile-First**: All UI must be designed for mobile screens first. Use Tailwind's responsive prefixes (`md:`, `lg:`) only if adapting for larger screens, but the default layout and interaction model must feel like a native mobile app.
2. **Premium Aesthetics**: 
   - Use curated, harmonious color palettes instead of standard default colors.
   - Implement modern typography (e.g., Inter, Roboto).
   - Use subtle micro-animations and smooth transitions for interactive elements.
   - Ensure a "Wow" factor upon first glance. The design should not look like a basic MVP.
3. **Components**: Keep components focused, reusable, and consistently styled using Tailwind.
